# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-07

### Added
* **Change Address Tracking for utxo based currencies:** Implemented a dedicated option to easily find and track change addresses for utxo based currencies.
* **Advanced Table Filtration:** Introduced a robust search feature allowing users to filter the generated data table by Keys, Addresses, or Derivation Paths.
* **Dynamic Derivation Paths:** Updated the UI to dynamically display the correct derivation path schemes specific to each selected cryptocurrency.
* **CodeMee Redesign:** Deployed a completely fresh, modern, and responsive user interface to enhance readability and overall user experience (UX).

### Fixed
* Addressed general bugs and implemented performance improvements over the base repository.
