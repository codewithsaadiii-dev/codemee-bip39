🔌 Offline Usage

For maximum security, you can use this tool without having to be online.

  • In your browser, select File > Save Page As..., and save this page as a single HTML file.
  • Transfer that file via USB to a completely offline (air-gapped) computer.
  • Double-click that file to open it in a browser safely and generate your keys.
